# New card project

This folder is the reusable starter. Copy the whole folder to `projects/<project-id>/` before adding any project-specific material. Do not work on a real set inside `_default`.

After copying:

1. Set `id` and `name` in `project.json`, and write the project brief here.
2. Define goals, language, deck colors, and planned card/layout scope. Leave undecided values unset.
3. Add reference files to `references/inbox/` and follow `references/README.md` to register and analyze them.
4. Create the required template previews according to the repository's template rules.
5. Add card definitions, illustrations, reviews, and exports as work progresses.

Open `index.html` for the initial offline overview. It is currently an empty-state snapshot. A shared overview generator will later populate and refresh it from actual project records; it does not automatically discover files yet.

## Folder guide

- `cards/`: card definitions, per-card illustrations, revisions, and reviews.
- `decks/`: card references and quantities for each deck.
- `references/`: originals and AI-organized findings about their contents and relevance.
- `templates/`: versioned reusable frame assets, geometry, and preview coverage records.
- `assets/`: project set symbol, card back, and branding.
- `notes/`: ideas, decisions, and playtests.
- `imports/`: preserved material from earlier projects.
- `output/`: composed cards, previews, print files, and reports.
- `tmp/`: disposable intermediates; do not store irreplaceable work here.
