# MTGGenerator

A reliable workflow for creating custom Magic-style card sets. AI creates structured card content and separate illustrations; a program renders them into reusable templates with consistent geometry, typography, and symbols.

Nael MTG and Arbeit MTG are the initial sets intended for inclusion. Their files have not yet been migrated.

- [Project instructions for AI contributors](AGENTS.md)
- [Template, preview, and rendering requirements](docs/template-rules.md)
- [Project folder structure and overview-page requirements](docs/project-structure.md)
- [Card projects](projects/README.md)

These documents are the implementation specification. This repository currently defines requirements; the renderer, project creation command, and generated overview pages are not implemented yet.
